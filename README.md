# Founder OS

Персональная операционная система предпринимателя: календарь, задачи и 90-дневные спринты, проекты, база знаний, аналитика и журнал результатов. Одно приложение для одного пользователя, интерфейс на русском.

## Быстрый старт

Нужен Node.js 18+ (проверено на 22).

```bash
npm install
npm run dev        # http://localhost:5173
```

Продакшен-сборка:

```bash
npm run build      # проверка TypeScript + сборка в dist/
npm run preview    # локальный просмотр сборки
```

`dist/` — статичный сайт: его можно выложить на Vercel, Netlify, Cloudflare Pages или любой хостинг. Для SPA-маршрутов настройте отдачу `index.html` на все пути.

## Проверки

```bash
npx tsc -b         # типы
npm test           # unit-тесты (vitest): расчёты, планировщик, спринт, store
npm run lint       # ESLint
```

## Данные

- Всё хранится в `localStorage` браузера (ключ `founder-os:data`) и сохраняется автоматически.
- Данные привязаны к браузеру и устройству. **Делайте экспорт JSON**: «Настройки и данные» → «Экспорт JSON». Там же импорт и полный сброс.
- Демо-данные загружаются только по кнопке. Они помечены бейджем «Демо» и удаляются одной кнопкой, реальные записи при этом не затрагиваются.
- Несколько вкладок синхронизируются между собой.

## Горячие клавиши

- `N` — новая задача.
- Кнопка «+» в правом нижнем углу — быстро добавить задачу, событие, проект, заметку или результат.

## Стек

React 18, TypeScript, Vite 5, Tailwind CSS 3, компоненты в стиле shadcn/ui на Radix, Lucide, React Router 6, Zustand 5, date-fns 4, react-big-calendar (месяц, неделя, день), gantt-task-react, Recharts, Vitest.

Архитектура и функциональность описаны в [FOUNDER_OS_SPEC.md](./FOUNDER_OS_SPEC.md).
