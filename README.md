# Founder OS

Персональная операционная система предпринимателя: календарь, задачи и 90-дневные спринты, проекты, база знаний, аналитика и журнал результатов. Одно приложение для одного пользователя, интерфейс на русском.

## Быстрый старт

Нужен Node.js 18+ (проверено на 22).

```bash
npm install
npm run dev        # http://localhost:5173
```

Продакшен-сборка:

```bash
npm run build         # проверка TypeScript + сборка в dist/
npm run build:single  # всё приложение одним файлом: dist-single/founder-os.html
npm run preview    # локальный просмотр сборки
```

`dist/` — статичный сайт: его можно выложить на Vercel, Netlify, Cloudflare Pages или любой хостинг. Для SPA-маршрутов настройте отдачу `index.html` на все пути.

## Проверки

```bash
npx tsc -b         # типы
npm test           # unit-тесты (vitest): расчёты, планировщик, спринт, store
npm run lint       # ESLint
```

## ИИ-ассистент (версия по ссылке в Claude)

Кнопка «Спросить ИИ», клавиша `/` или командная строка на главной. Пишите как в мессенджере:
«добавь задачу: КП для инвестора до пятницы, важно, 3 часа», «закрыл договор с поставщиком»,
«получили первую оплату 150 000 ₽ по ARGO», «встреча с банком в четверг в 15:00», «что горит?».
Ассистент сам создаёт и обновляет задачи, результаты, события, заметки и проекты; каждое действие
видно в журнале и отменяется кнопкой «Отменить». Есть голосовой ввод. Работает на вашем аккаунте
Claude — без ключей API. В скачанном файле ассистента нет.

## Данные

- **По ссылке в Claude** данные хранятся в облаке Claude и синхронизируются между устройствами. При первом открытии записи, сделанные раньше в этом браузере, переносятся в облако автоматически.
- **В скачанном файле** — в `localStorage` браузера (ключ `founder-os:data`), только на этом устройстве.
- Резервная копия: «Настройки и данные» → «Экспорт JSON». Там же импорт и полный сброс.
- Демо-данные загружаются только по кнопке. Они помечены бейджем «Демо» и удаляются одной кнопкой, реальные записи при этом не затрагиваются.
- Несколько вкладок синхронизируются между собой.

## Горячие клавиши

- `N` — новая задача.
- Кнопка «+» в правом нижнем углу — быстро добавить задачу, событие, проект, заметку или результат.
